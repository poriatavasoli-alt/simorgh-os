# Simorgh OS 11.0 Quantum Edition

سیستم‌عامل تحت وب حرفه‌ای با هویت سیمرغ طلایی · RTL فارسی · هسته کوانتومی · طراحی مکعبی

## اجرا

فایل اصلی را در مرورگر باز کنید:

- [`index.html`](./index.html) (لودر + payload فشرده gzip)

**توجه:** برای بارگذاری کامل، فایل‌های `payload0.js` تا `payload3.js` باید کامل باشند. نسخه کامل standalone در فایل محلی `Simorgh-OS-11.0.html` موجود است.

حساب پیش‌فرض:

| کاربر | رمز | نقش |
|--------|------|------|
| `simorgh` | `1234` | مدیر |
| `guest` | `guest` | مهمان |
