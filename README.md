# Simorgh OS 11.0 Quantum Edition

سیستم‌عامل تحت وب حرفه‌ای با هویت سیمرغ طلایی · RTL فارسی · هسته کوانتومی

## نسخه کامل و مستقل

باز کردن [`index.html`](./index.html) نسخه **کامل و مستقل** را در مرورگر بارگذاری می‌کند (از طریق payloadهای فشرده).

پس از بارگذاری موفق، document کامل Simorgh OS 11.0 Quantum در تب مرورگر قرار می‌گیرد — بدون نیاز به فایل جانبی بیشتر.

فایل محلی `Simorgh-OS-11.0.html` (حدود ۳۳۲ کیلوبایت) نیز نسخه standalone کامل است.

## فایل‌های مخزن

- `index.html` — لودر PWA
- `payload0.js` … `payload4.js` — بخش‌های فشرده نسخه کامل
- `manifest.json` · `sw.js` — پشتیبانی PWA
- `Simorgh-OS-11.0.html` — نشان‌گر نسخه کامل (محتوای کامل از طریق لودر)
